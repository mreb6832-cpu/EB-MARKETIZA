EB-MARKETIZA PWA

1. Upload these files beside index.html:
   manifest.json
   service-worker.js
   install.js
   icon-192.png
   icon-512.png

2. Add the contents of index-integration.html to index.html:
   - first part inside <head>
   - second part immediately before </body>

3. Commit changes and wait for Vercel deployment.

4. Android: open https://ebmarketiza.vercel.app/ in Chrome and install.
5. iPhone: open the site in Safari -> Share -> Add to Home Screen.

This keeps the existing EB-MARKETIZA website, Supabase, cart and payment system.
